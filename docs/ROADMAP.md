# Roadmap

Senlay provides coordinate-level environmental context in an evaluation MVP for autonomous systems and AI applications. Current interfaces include REST, MCP and signed station ingestion. Aerial, marine and field robotics workflows require further validation. Route/time-window and platform-specific mission evaluation remain planned. The following tracks describe direction, not a release schedule.

## 1. Better Sensing

- broader sensor coverage
- clearer confidence scoring
- stronger source labeling
- more robust coastal and terrain interpretation

## 2. Better Agent Integration

- cleaner agent onboarding
- richer context formats
- framework-friendly examples
- easier tool definitions for AI systems

## 3. Better Developer Experience

- OpenAPI documentation
- JavaScript and dependency-free Python station connectors
- safe simulated-data commissioning
- stronger public docs
- production-grade usage guidance

The direction is steady: make AI more useful when the answer depends on physical reality.
