# Use Cases

## AI Agents

Agents can use Senlay before answering questions about the physical world:

- "Is it windy there right now?"
- "Is this location safe for an outdoor activity?"
- "What changed in the environment today?"
- "Is this coastal condition relevant for a session?"

## Outdoor and Coastal Safety

Senlay is especially relevant where conditions change quickly:

- wind sports
- surfing and hydrofoiling
- coastal travel
- exposed work sites
- weather-sensitive field operations

## Developer Products

Developers can use Senlay as a physical context layer inside:

- assistant tools
- planning dashboards
- location-aware apps
- automation workflows
- environmental alerts
- agent frameworks

## Field Operations

Physical context matters for:

- timing
- route choice
- gear choice
- worker safety
- risk communication
- environmental awareness
